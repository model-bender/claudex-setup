# Ask Claude to Save a Mod as a Plugin or It Is Temporary

## TL;DR

Tristen says mods Claude builds are temporary by default; to keep one, ask Claude to save it as a plugin and install it. Shared mods install like any plugin through /plugin.

## Why it matters

Without saving, the mod will not be there each time you open Claude.

## How to apply

Once you like a mod, tell Claude to save it as a plugin and install it.

Checked: /plugin appears in the 2.1.296 binary (count 353); the temporary-by-default behavior is Tristen's statement, not tested.
