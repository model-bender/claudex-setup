# Describe a Prompt-Upgrade Mod That Asks 3 Questions, Shows Before and After, and Runs the Result

## TL;DR

Tristen O'Brien's mod intercepts a short prompt, asks a few multiple-choice questions, shows your text beside a fuller rewrite you can edit, copy or run.

## Why it matters

Short prompts produce thin output and he often lacks time to write a good one. His example turned 'Build me a 30-day marketing plan for a pizza company' into a longer prompt built from answers on goal (more online orders), business type and budget.

## How to apply

Ask Claude Code to build a mod that, on submit, opens a screen with a few clarifying questions, then side-by-side original and upgraded prompts with edit, copy and run actions; run puts it into Claude. He says he wrote no code and shares the prompts free; I did not see them. Checked: 'mods' exist (plugin-authoring skill listed in 2.1.303); I did not build or test it.
