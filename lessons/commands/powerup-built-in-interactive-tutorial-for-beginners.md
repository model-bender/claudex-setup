# Run /powerup, the Built-In 10-Lesson Interactive Tutorial, to Onboard Beginners

## TL;DR

/powerup launches a built-in 10-lesson interactive ASCII tutorial inside Claude Code; run new users through it to get them to roughly 80% before pointing them at advanced tooling like /insights.

## Why it matters

It is a built-in teaching surface inside the tool itself, so a beginner learns by doing rather than by reading docs. Getting someone to roughly 80% competence this way first means personalized feedback tools like an /insights report card land on a user who already has the basics down.

## How to apply

Type /powerup and work through its ten interactive lessons. Point teammates new to Claude Code at it as their first step, before layering on usage-derived recommendations such as those from /insights.
