# Run /keybindings to List and Customize Claude Code's Key Bindings

## TL;DR

Claude Code has a /keybindings command that shows the current key bindings and lets you change them, particularly relevant in chord-capable terminals like Ghostty.

## Why it matters

The creator names this directly among new Claude Code features: "If you're using something like Ghosty, you can do /keybindings and see many of the key bindings that you have and change any that uh you may want to."

## How to apply

Type /keybindings in Claude Code to see the current bindings and edit any you want to remap.
