# Cycle Opus Effort (Low/Medium/High) With the Arrow Keys Mid-Session

## TL;DR

Claude Code lets you switch Opus between low, medium, and high effort using the arrow keys, useful when the model is overthinking a simple task.

## Why it matters

The creator flags this as the fix for Opus "overthinking on a given task," describing pressing the arrow keys to switch between the three effort levels without leaving the session.

## How to apply

Press the arrow keys in Claude Code to step Opus's effort level between low (simple tasks, lower cost), medium (balanced agentic work), and high (complex reasoning/hard coding problems).
