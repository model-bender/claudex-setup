# Press Cmd+J for an Inline Terminal Inside a Codex Thread

## TL;DR

Cmd+J opens a terminal panel directly inside a Codex app thread, so you can run a command without leaving the thread or switching to a separate terminal app.

## Why it matters

In Claude Code you would open a split pane or drop to a command-line mode to run something yourself mid-task. Codex app puts a terminal in the same window as the thread, so checking what the agent just did (git status, a test run, a log tail) costs one keystroke instead of a context switch.

## How to apply

Press Cmd+J while in a Codex app thread to toggle the inline terminal panel, run your command, and press it again to hide it.
