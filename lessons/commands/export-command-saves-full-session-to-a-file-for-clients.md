# Use /export to Save the Whole Session as a File to Hand to a Client

## TL;DR

When you want to share an entire diagnostic session rather than a single response, /export saves it to a file you can send directly, so the recipient can follow the full reasoning trail.

## Why it matters

Unlike /copy (which copies one response or a chosen section), /export captures the complete session for cases like showing a client exactly how you diagnosed an incident from start to finish.

## How to apply

Run /export, choose 'save to file,' and send the resulting file directly to the client or teammate instead of manually reconstructing a summary of the session.
