# Press Shift+Tab to Cycle Plan Mode and Accept-Edits Mode

## TL;DR

Shift+Tab switches Claude Code between plan mode and accept-edits mode without typing a command.

Shift+Tab cycles through Claude Code's permission modes; pressing it repeatedly is how you land on auto mode without typing a command.

## Why it matters

John Kim uses this constantly since he starts almost every new feature in plan mode and switches modes many times a session; memorizing it removes friction from the mode-switching habit.

While turning on auto mode, the presenter says: 'we also want to turn on auto mode, which you can simply do by pressing shift tab until you have auto mode on.'

## How to apply

Press Shift+Tab in the input box to cycle through modes (e.g., accept-edits to plan mode).

In a Claude Code terminal session, press Shift+Tab one or more times to cycle through permission modes until the statusline shows auto mode is active.
