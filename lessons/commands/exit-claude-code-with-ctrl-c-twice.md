# Exit Claude Code by Pressing Ctrl+C Twice

## TL;DR

Ctrl+C twice quits Claude Code from the terminal; a single Ctrl+C does not exit.

## Why it matters

Beginners hunting for a quit command can get stuck mid-session; the video calls this out as one of the only terminal commands you actually need to know to run Claude Code.

## How to apply

Press Ctrl+C twice in the terminal to close Claude Code. Use /clear if you just want to wipe its memory instead of quitting and reopening.
