# Run /memory to Inspect Claude Code's Automemory Structure

## TL;DR

The /memory command shows imported, project, and user memory, and lets you auto-open the automemory folder to browse the index and its linked files.

## Why it matters

Most users only know about CLAUDE.md; /memory reveals the automemory index and per-topic files Claude already maintains in the background, so you can see and edit what it is drawing on instead of guessing.

## How to apply

Type /memory and press enter inside a project. Choose 'autoopen memory folder' to see the memory.md index and its linked feedback/topic files under the project's automemory directory.
