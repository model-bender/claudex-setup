# Press Ctrl+T to View the Agent Team's Current Task List

## TL;DR

Ctrl+T pops up the list of tasks the agent-team orchestrator has assigned across teammates, letting you see what's in flight without switching panes.

## Why it matters

It's the fastest way to check team progress without opening the split-pane view or asking the orchestrator directly.

## How to apply

While an agent team is running, press Ctrl+T. Note it was still somewhat flaky and experimental at time of recording, sometimes needing more than one press.
