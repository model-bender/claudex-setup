# Run /mobile to Get a QR Code for the Mobile App

## TL;DR

Run /mobile in Claude Code to display a QR code that links straight to the iOS or Android app download.

## Why it matters

It's a fast, no-search way to get the mobile companion app installed.

## How to apply

Type /mobile in a Claude Code session and scan the QR code it displays with your phone.
