# Use /plan to Toggle Planning Mode, and Run It Again to Recall the Existing Plan

## TL;DR

/plan turns Planning Mode on as an alternative to the Shift+Tab-twice shortcut; if you already have a plan built in the session, running /plan again redisplays that same plan instead of starting a new one.

## Why it matters

Not knowing /plan can recall the existing plan means people re-describe or re-derive a plan that Claude already produced, wasting a turn.

## How to apply

Type /plan to enter Planning Mode. If a plan already exists in the session, typing /plan again shows you that same plan rather than prompting for a new one.
