# Press Cmd+Option+B to Open Codex App's Git Review Panel

## TL;DR

Cmd+Option+B shows or hides the Codex app's git changes panel, where you stage, revert, and leave inline comments on a diff for the agent to iterate on.

## Why it matters

The git review panel (stage, revert, comment inline on a diff and have the agent act on the comment) is one of the Codex app's standout surfaces, and it is easy to miss because reaching it otherwise means clicking through the UI. Reviewing the diff in the window that produced it is what keeps the comment-and-iterate loop tight.

## How to apply

Press Cmd+Option+B in the Codex app to toggle the git review panel, then stage, revert, or comment on individual hunks and let the agent address the comments in the same thread.
