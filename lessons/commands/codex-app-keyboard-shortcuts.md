# Learn Codex App's Five Keyboard Shortcuts: Threads, Palette, Terminal, Git Panel, Dictation

## TL;DR

Cmd+[ and Cmd+] move backward and forward between open threads in the Codex Electron app.

Cmd+K opens a general find/command palette in Codex app that can jump to Settings or run any available command.

Cmd+J opens an inline terminal panel directly inside a Codex app thread.

Cmd+Option+B shows or hides Codex app's git review/changes panel.

Codex app has a built-in voice dictation mode bound to Ctrl+M, so you don't need a third-party dictation tool to speak prompts.

## Why it matters

The presenter calls this out as a real shortcut (even while noting it feels a bit janky); without it you have to click through the sidebar to switch threads.

It replaces hunting through menus for settings or actions with a single fuzzy-searchable palette.

In Claude Code you would have to open a split pane or a command-line mode to get a terminal; Codex app gives you one with a single shortcut.

The git review panel (stage, revert, inline comment-and-iterate on a diff) is one of Codex app's standout features, and this shortcut brings it up without clicking through the UI.

Users often reach for external apps for voice input; Codex ships one natively, which is worth knowing before installing something else.

## How to apply

In Codex app, press Cmd+[ to go to the previous thread and Cmd+] to go to the next one.

Press Cmd+K in Codex app to open the palette, then type to fuzzy-find settings or commands.

Press Cmd+J while in a Codex app thread to toggle an inline terminal panel.

Press Cmd+Option+B in Codex app to toggle the git changes/review panel.

Press Ctrl+M in Codex app to start voice dictation, speak your prompt, then let it drop into the input box as text.
