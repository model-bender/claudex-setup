# Use the /v Voice Command, Hold Spacebar to Speak, Works in 20+ Languages

## TL;DR

Claude Code's built-in voice mode is invoked with /v, you hold the spacebar while speaking your instruction, and it now supports more than 20 languages.

Claude Code's own /voice command is a free speech-to-text mode (hold space to record) supporting about 20 languages, and unlike generic dictation tools, it can pick up your project-specific terms because it has access to your CLAUDE.md.

## Why it matters

Speaking is faster than typing for longer or more context-rich instructions, and not knowing the exact invocation (the /v command plus hold-to-talk spacebar mechanic) is what keeps people stuck typing instead.

Generic dictation tools like WhisperFlow don't know your project's specific names and terms; /voice's access to CLAUDE.md gives it project-aware transcription, and it costs nothing extra since it's built in.

## How to apply

In a Claude Code session, run /v, hold the spacebar, and speak your instruction; release to submit. Works without a third-party dictation tool, though tools like Whisper Flow are an alternative if you want dictation outside this specific flow.

Type /voice to enable voice mode, then hold space to record your prompt; release to transcribe. Use it especially when juggling multiple Claude Code instances, since you can speak commands rather than typing between windows.
