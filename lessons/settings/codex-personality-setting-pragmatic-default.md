# Switch Codex's /personality Setting to Pragmatic for Concise Output

## TL;DR

Codex has a /personality setting toggling between Friendly and Pragmatic; Pragmatic gives concise, task-focused, direct responses.

## Why it matters

The default Friendly personality adds more conversational padding than most coding/automation work needs.

## How to apply

Run /personality (or open a side chat and run it there) and select Pragmatic to make Codex's default tone concise and task-focused.
