# Claude Code's Status Line Shows a Clickable Link to the Branch's Open PR

## TL;DR

If you're on a branch with an open PR and have the GitHub CLI installed, Claude Code's status line displays a link you can click to open that PR directly.

## Why it matters

The creator states: "if you move on to a branch that has an active PR and you have the GitHub CLI installed, then you will see at the bottom in the status line. So you can press a command and then click on it and it will open up that PR," a one-click shortcut to the PR without leaving the terminal.

## How to apply

Install and authenticate `gh` (GitHub CLI); when you check out a branch with an active PR, look at Claude Code's status line for the PR link and use the modifier-key click to open it in your browser.
