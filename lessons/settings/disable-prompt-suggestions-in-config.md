# Turn Off Auto-Filled Prompt Suggestions via /config

## TL;DR

Claude Code can proactively suggest your next prompt (e.g. suggesting 'push the changes' right after a commit) and let you Tab-autofill it; turn this off via /config if you find it distracting while coding.

## Why it matters

The feature is meant as a convenience but was reported as annoying during focused coding work.

## How to apply

Run /config, find the prompt suggestions setting, and turn it off.
