# Don't Ask Claude Design to Optimize Your Copy: Use a Copywriting or CRO Skill Instead

## TL;DR

Claude Design is for the visual layer; when the marketing text on a page needs work, hand that off to a dedicated copywriting or conversion-rate-optimization skill rather than iterating on wording inside Claude Design.

## Why it matters

Claude Design's iteration loop (comment, edit, draw, tweaks panel) is built around visual/layout changes and costs tokens per round; text quality is a different discipline with its own tooling, and mixing the two wastes Design's limited quota on something a purpose-built skill does better.

## How to apply

Keep copy edits inside Claude Design to fixing what's obviously wrong (typos, wrong section text) via direct edit. For anything requiring actual copywriting or CRO judgment, export or hand the content to a copywriting/CRO skill in Claude Code instead of re-prompting Claude Design.
