# The # Shortcut for Adding a Note to CLAUDE.md Was Removed

## TL;DR

The `#` shortcut that used to let you quickly append a note to CLAUDE.md by typing `#` and a note has been removed.

## Why it matters

Anyone relying on that muscle-memory shortcut will find it silently stops working after updating.

## How to apply

Add notes to CLAUDE.md by opening and editing the file directly (or asking Claude to do it) instead of typing a `#`-prefixed message.
