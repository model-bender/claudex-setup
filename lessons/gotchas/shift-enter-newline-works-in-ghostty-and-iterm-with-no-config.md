# Shift+Enter for a New Line Now Works in Ghostty and iTerm Without Extra Config

## TL;DR

Terminals like Ghostty and iTerm now support Shift+Enter to insert a new line in the prompt box out of the box, where before you had to change terminal configuration to make that keybinding pass through.

## Why it matters

People who set this up once for an older Claude Code version may still be carrying now-unnecessary terminal config, or newcomers may not realize the shortcut works without any setup at all.

## How to apply

In Ghostty or iTerm, just press Shift+Enter to add a new line while typing a prompt; no terminal keybinding configuration is required anymore.
