# A Claude Design Chat Accumulates Multiple Files: Switch Between Them at the Top Left

## TL;DR

Iterating inside one Claude Design chat often creates several separate files, not one evolving file. The switcher for them sits at the top left of the design page.

## Why it matters

Marchese flags this mid-walkthrough because it is easy to think an earlier version is gone when the model has actually written a new file and left the old one behind. Knowing the switcher exists turns what looks like a lost iteration into a version you can go back to and compare against.

## How to apply

When a Claude Design chat has run for several rounds, open the file list at the top left of the design page to find the earlier outputs from the same conversation, and switch between them to compare or recover a version.
