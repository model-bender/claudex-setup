# Say 'Reorganize Memory' to Trigger a Consolidation Pass Over Your Memory Files

## TL;DR

In a project set up with a structured CLAUDE.md memory-management prompt, typing the phrase 'reorganize memory' makes Claude read all memory files, delete empty/duplicate ones, merge related entries, split overloaded files, and refresh the memory.md index.

## Why it matters

Structured memory files accumulate empty daily-session stubs and duplicate entries over weeks of use; without an explicit trigger phrase nothing cleans them up and the index drifts from what's actually useful.

## How to apply

After setting up a domain/tools/general memory structure in CLAUDE.md, periodically open a session in plan mode and type 'reorganize memory'. Review the plan (delete empties, merge duplicates, split overloaded files, add cross-references, update memory.md), then approve execution.
