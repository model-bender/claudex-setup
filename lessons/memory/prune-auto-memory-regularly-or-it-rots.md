# Prune Claude Code's Auto-Memory Regularly or It Fills With Noise

## TL;DR

Letting Claude Code's built-in auto-memory write itself without ever reviewing it tends to accumulate low-value notes that make it less useful over time, not more.

## Why it matters

The creator observed that auto-memory "ends up writing a lot of like nonsense and like filling up the memory with too much noise that doesn't make it useful," concluding that "unless you're actually pruning the memory regularly to remove any things that aren't helpful, it may not actually do that good of a job in the long term."

## How to apply

Periodically open and edit the auto-memory files yourself, deleting stale or low-value notes, rather than trusting the feature to self-maintain; if you won't do that pruning, weigh disabling auto-memory instead.
