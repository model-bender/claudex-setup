# Limit which tasks an agent can see, not only what it can do

## TL;DR

An agent that can see unassigned work may decide to be proactive about it. Scope its view to the tasks that are its own.

## Why it matters

The guest's incident was two access problems, not prompt problems: the agent could see a task that was not assigned to it, and it had a send button.

## How to apply

Filter the task list or inbox the agent reads to items assigned to it, in the integration and not in the prompt. The source names the access problem and says a rule in the tools is a restriction while a rule in the prompt is a suggestion; the filter itself is this lesson's inference.
