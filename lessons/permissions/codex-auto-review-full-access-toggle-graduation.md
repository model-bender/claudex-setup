# Graduate From Codex's Default Permissions to Full Access Once You Trust Your Flow

## TL;DR

Codex's Settings has an Auto Review / Full Access toggle that's off by default; start on default permissions while learning a new project or skill, then flip to Full Access once you trust it.

## Why it matters

Default permissions pause Codex to ask you to approve things like network access, which is safer while you're still shaping a workflow; Full Access removes that friction but removes your safety net too.

## How to apply

Go to Settings, find the Auto Review / Full Access toggle (shown in orange when enabled), leave it off for new/unfamiliar projects and skills, and only switch it on once you've seen the flow work reliably on default permissions.
