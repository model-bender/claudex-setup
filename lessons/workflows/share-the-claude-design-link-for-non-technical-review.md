# Collect Teammate Feedback by Sharing the Claude Design Link, Not Screenshots

## TL;DR

Share the design directly with reviewers so they comment on the artifact itself, instead of asking them to run the app or trading screenshots in chat.

## Why it matters

Marchese's contrast with Claude Code is the point: a non-technical reviewer cannot pull the branch, install dependencies and spin up a dev server to see a change, so feedback degrades into screenshots and vague chat descriptions that then have to be translated back into element-level edits. A shared design link removes every one of those steps and lands the feedback already anchored to the element it concerns, ready to send to Claude as a batch.

## How to apply

Use Claude Design's share on the project, send the link to the reviewers, and ask them to comment directly on the elements they want changed. Then work the comment queue yourself and send it to Claude in one pass.
