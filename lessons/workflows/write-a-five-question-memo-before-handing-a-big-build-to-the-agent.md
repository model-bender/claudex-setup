# Write a Five-Question Memo (What, Who, What It Is Not, What Done Looks Like, Smallest Proof) Before Building

## TL;DR

Before a big project, have Claude interview you into a short memo answering five questions, so the build has one clear point of view.

## Why it matters

Austin presents it as the first step of Alexandr Wang's process: decide the destination before pressing the gas. Without a single point of view, he says, you get a Frankenstein with more and more features.

## How to apply

Ask Claude to interview you until it can write a memo that answers: what it is; who it is for (name a real person); what it is not; what done looks like; what the smallest version is that proves it is possible. Austin adds a sixth, which features you want.

Checked: No mechanism claim. Wang's own process is secondhand via Austin Marchese, not independently verified.
