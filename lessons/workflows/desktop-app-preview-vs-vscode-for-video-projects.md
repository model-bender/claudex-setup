# Use the Claude Desktop App's Preview Pane for Quick Localhost Checks, VS Code for Full Project Visibility

## TL;DR

When doing agent-driven video editing, the Claude desktop app can preview a running localhost render inline during the conversation, while VS Code lets you see every project file, asset, and past render side by side.

## Why it matters

Each has a different edge: the desktop app saves you tabbing to a browser to check a render, while VS Code is better once a project accumulates many render versions and dropped-in assets you want to browse directly.

## How to apply

For a one-off quick video check, keep working in the Claude desktop app and use its built-in preview panel. For an ongoing video-editing project with many iterations, work from VS Code so you can inspect the file tree, assets, and render history directly.
