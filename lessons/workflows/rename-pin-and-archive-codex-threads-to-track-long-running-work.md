# Rename, Pin, Section and Archive Codex Threads So the Sidebar Tracks What Is Running

## TL;DR

Rename a thread for its high-level task, pin the active ones, group them in custom sections, and archive finished ones to keep projects and context tidy.

## Why it matters

John Kim says this is underrated: with a spinning indicator he knows a day-long monorepo migration is still running, sees worktree and approval-needed markers, and can ignore the rest. The CLI has agent commands for similar things but he calls them clunky.

## How to apply

1. Double-click a thread to rename it. 2. Pin, or drag it into a new section. 3. Archive threads when done. Checked: app UI behaviour is the speaker's, not verifiable from codex-cli 0.163.0.
