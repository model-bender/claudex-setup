# Export a Claude Design Project to Figma, Canva, or PowerPoint, Not Just HTML

## TL;DR

Claude Design's export options include Figma, Canva, and PowerPoint alongside the raw HTML/zip export.

## Why it matters

Handing a finished prototype to Claude Code is only one export path; exporting straight to Figma/Canva/PowerPoint instead gets it into a design or presentation tool where it can be finished by hand with no further Claude Design or Claude Code usage needed.

## How to apply

In Claude Design's export/share menu, choose Figma, Canva, or PowerPoint instead of HTML when the next step is hand-editing in a design or slide tool rather than code.
