# Rebuild Stale Decks, Proposals and PDFs by Uploading the Original Into Claude Design

## TL;DR

Upload the outdated artifact itself (a Canva proposal, an old deck, a research PDF) alongside your published design system and ask Claude Design to rebuild the whole thing, then finish it on the canvas.

## Why it matters

Collateral rots silently: Marchese's client proposals were still in his old branding months after the rebrand because re-laying-out a deck by hand is the task everyone deprioritises. Claude Design's design system already holds the palette, type and components, so the only missing input is the document's own content and section order, which the uploaded file supplies. The result is customer-ready rather than a slide of AI slop, because you can tweak the wording directly on the page afterwards instead of re-prompting.

## How to apply

Publish the design system first, then in a new Claude Design project attach the original file (Canva export, PDF, deck) and prompt to rebuild it end to end in that system. Work the backlog in one sitting: old proposals, research studies, one-pagers. Finish the last 10% by editing text in place on the canvas rather than prompting for micro-tweaks.
