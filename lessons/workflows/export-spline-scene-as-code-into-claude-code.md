# Export a Remixed Spline 3D Scene as Code and Hand It to Claude Code

## TL;DR

Spline's community library lets you remix an existing 3D scene, restyle its colors to match your brand palette, then use Export > Code > Copy to get a snippet you paste straight into a Claude Code prompt to embed it.

## Why it matters

Building a 3D hero animation from scratch is expensive; remixing a community scene and reusing your Claude Design brand colors gets a branded, on-page 3D graphic in minutes instead of hours of manual Spline work.

## How to apply

In Spline, open the community tab, remix a scene, delete/recolor shapes to match your Claude Design brand colors, click Export > Code > Copy, then paste that code into Claude Code with a prompt naming the target section (e.g. 'add this to the hero section').
