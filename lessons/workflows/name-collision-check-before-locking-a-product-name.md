# Ask the Agent to Run a Name-Collision Check Before Locking In a Product Name

## TL;DR

Before committing to a product name, have the agent search for existing products already using that name or a near-identical one.

## Why it matters

Codex ran this automatically during the branding pass and it changed the shortlist: 'the collision check eliminated several obvious names because close kit is already being used by nearly identical AI proposal product... client ready is already being used for an AI report service.' This caught naming collisions the creator would not have found by browsing manually in the time available.

## How to apply

When asking an agent to propose product or brand names, add an explicit step: search for each candidate name plus the product category and flag any name already in use by a similar product before locking one in.
