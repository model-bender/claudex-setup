# Click the Plus Button in the Web/Desktop Diff View to Send a Line-Referenced Comment

## TL;DR

The web and desktop Claude Code diff view shows added/deleted lines, and clicking the plus button next to any line lets you type a suggestion or comment that gets sent as a new message tagged with that exact file and line reference.

## Why it matters

The transcript describes this directly: 'the web and desktop version of Claude Code now includes a diff view where it shows the lines deleted and added, and you can include your own suggestions and comments by clicking on any of the plus buttons and then typing something in here. So pressing enter on a suggestion, it will then send it as a brand new message with the line and file reference.' This is faster and more precise than describing a location in prose.

## How to apply

While reviewing a diff in the web or desktop client, hover a specific line, click its plus icon, type your comment/suggestion, and press enter; Claude receives it as a message pre-tagged with that file and line number rather than you having to describe the location yourself.
