# On a Pro or Max Plan, Build the Animation in Claude Design and Use Its Comment Button to Edit One Spot

## TL;DR

Claude Motion was Team and Enterprise only in this video, but the same prompt in Claude Design (Artifacts, then Design) produced a near-identical animation on Pro or Max, editable by commenting on a single element.

## Why it matters

Tristen O'Brien ran one shadow-puppet-theater commercial prompt in both. Both write code rather than painting pixels, so a single element can be changed without redoing the rest. Motion took about 28 minutes and Design about 48 for a 20-second piece; Design had no editor or Tweaks panel and exported as MP4, while Motion offered video or GIF export, resolution and frame rate options.

## How to apply

1. In Claude, open Artifacts and choose Design. 2. Paste the animation prompt and say 'build an animation'. 3. For a local change, use the comment button, click the element (his example: the water in the voyage scene, asking for a thunderstorm); Claude reworks only that section (about 2 minutes). 4. Download the MP4. Expect long, usage-heavy runs and prefer Opus 5.5 over Sonnet 5.5 for the premium look; on the free plan Sonnet 5.5 was the highest model offered (Opus 5.5 and Fable 5.1 asked for an upgrade) and he judged the result probably unusable there. Checked: plan availability and timings are the creator's observation from one run in October 2026, not checked against current docs; he says Pro works but showed only a Max account.
