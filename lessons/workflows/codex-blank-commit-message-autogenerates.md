# Leave the Commit Message Blank in Codex App to Auto-Generate One

## TL;DR

Leaving the commit message field empty in Codex app's git panel makes it auto-generate a commit message for you.

## Why it matters

It's a small but genuinely time-saving default most users would not discover without being told.

## How to apply

In Codex app's git panel, stage your changes, leave the commit message box empty, and commit; Codex fills in a generated message.
