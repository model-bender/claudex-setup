# Keep a Separate To-Do List for Claude Code, Distinct From Your Own

## TL;DR

Maintain your personal to-do list (e.g. in Todoist) and a second list specifically for items you want Claude Code to execute itself, and tell it explicitly which items belong to which list.

## Why it matters

This gives Claude Code a durable, explicit backlog of self-executable work (e.g. checking a post's performance 3 days after publishing) separate from tasks that need a human, so it knows what's its job versus yours without re-asking each time.

## How to apply

Create a to-do list dedicated to Claude Code alongside your personal one. When adding an item, specify whether it goes on your list or Claude Code's, e.g. 'add to your to-do list: 3 days later, check how that posted in terms of views and likes, and any learnings from the comments.'
