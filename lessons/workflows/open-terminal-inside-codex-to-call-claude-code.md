# Open a Terminal Inside the Codex App to Call Claude Code in the Same Working Directory

## TL;DR

Codex's app has a View > Terminal option; open it to run another CLI, like Claude Code, directly in your current project folder, then hand its output back to Codex.

## Why it matters

This lets you mix tools without leaving Codex or manually re-pointing a second terminal at the right directory.

## How to apply

In the Codex app, click View, open the terminal, run `claude` to brainstorm or generate a file (e.g. a plan), then @-tag that file back in the Codex chat and ask Codex to execute it.
