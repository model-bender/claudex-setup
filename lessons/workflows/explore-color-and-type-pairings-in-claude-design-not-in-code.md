# Explore Color and Type Pairings in Claude Design, Where You Can Click Through Them on the Live Design

## TL;DR

Ask Claude Design to explore color and type pairings against your existing brand, then click between the pairings it produces and watch them apply to the real design, instead of editing color values in Claude Code.

## Why it matters

Marchese's rule is that seeing beats reasoning about color: rather than theorising about color science, have the tool render the options on the artifact you actually care about. Claude Design makes pairing selection a first-class control, so switching palettes is a click on the live design. The same exploration in Claude Code means editing code, rebuilding and looking, which he calls out as much slower for exactly this class of change.

## How to apply

Prompt 'explore color and type pairings for <brand>' with your site or channel attached so the options are anchored to your existing brand rather than invented. On an existing design, use the pairing selector to click through each option and watch it apply before committing. Keep code-level color work in Claude Code for tokens and implementation, not exploration.
