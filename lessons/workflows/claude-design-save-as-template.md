# Save a Finished Claude Design Project as a Template for Reuse

## TL;DR

Once a Claude Design project is done, use Share > 'save as template' to turn it into a reusable starting point for future projects instead of rebuilding a similar brief from scratch.

## Why it matters

The presenter lists this among the Share options: 'you can duplicate the project or save it as a template,' setting up reuse of a finished design as a new project's starting point via the 'from template' option covered elsewhere in the same walkthrough.

## How to apply

Click Share on a finished Claude Design project, choose 'save as template,' and start future similar projects from the 'From template' tab instead of a blank prompt.
