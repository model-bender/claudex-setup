# Drop a Finished Project's Exported HTML Into a New Claude Design Project to Carry the Brand

## TL;DR

Export a finished Claude Design project as standalone HTML, open a NEW project, drop the file in, and prompt from there: the rendered page carries far more brand signal than a written description or a design system alone.

## Why it matters

Describing your brand in tokens or prose loses most of it. Feeding the actual rendered page gives the model the real buttons, fonts and colours to copy from. A promo video built this way inherited the source site's exact buttons, fonts and colours, which is the difference between output that looks like yours and output that looks like a template.

## How to apply

In the finished project use Share, then standalone HTML, and download the file. Open a new project, drop the HTML in as context, and state what you want built from it, for example 'turn this into an animated release video'. Use this wherever a design system alone is not carrying enough brand signal.
