# Claude Code Snapshots a Checkpoint Before Every File Edit, With No Setup Required

## TL;DR

Before each file edit, Claude Code automatically saves a session-level checkpoint, so there is always a rewind point without you doing anything to enable it.

## Why it matters

You don't need to manually save state to get undo protection; it happens per edit by default, which is what makes the rewind menu reliably useful mid-session.

## How to apply

Work normally; a checkpoint is captured before every file edit automatically. Open the checkpoint/rewind list at any time to jump back to a specific prompt or edit point.
