# Keep the Camera Static When Generating a Background Loop Video for Claude Design

## TL;DR

When prompting an AI video model for a hero/background clip meant to loop endlessly, specify that the camera does not move so the loop isn't jarring.

## Why it matters

The creator's video prompt was explicit that "the camera isn't moving. It's basically just a still frame or a still video... being animated," which is what let the 8-second clip loop smoothly behind hero text without a visible seam.

## How to apply

When writing the video-generation prompt for a hero/background loop clip, state explicitly that the camera stays static; combine this with matching first-and-last frames for the actual loop point.
