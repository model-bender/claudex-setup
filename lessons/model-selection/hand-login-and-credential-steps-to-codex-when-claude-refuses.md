# When Claude Refuses to Copy a Credential or Click Log In for You, Hand That Step to Codex

## TL;DR

Mark says Claude's computer use lags Codex's and Claude refuses to copy credentials or use an API key even with permission, while Codex usually does it.

## Why it matters

He says to do this only if you are responsible enough to know where it is safe. If connectors, CLIs and MCPs cover the task and no login is needed, Claude is fine.

## How to apply

Split the project into phases and send the login or credential phase to Codex. Mark's other option is doing those micro steps yourself.
