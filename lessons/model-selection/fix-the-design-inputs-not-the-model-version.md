# A Newer Model Will Not Fix Design Slop, the Inputs Will

## TL;DR

Given the same prompt, assets, brand guidelines and design skill, two model generations produced sites that were hard to tell apart. If the output looks generic, spend the effort on brand guidelines, reference sites, components and a verification loop, not on upgrading the model.

## Why it matters

Nate Herk ran the same site builds on Fable 5 and Fable 5.1 with identical prompts, assets and skill and reports none of them clearly blew the other one out of the water, with the only consistent difference being cost (roughly 1824 versus 2022, 1283 versus 2164 on his counters). His conclusion is that the seven input-side things he lists matter more than which model you explicitly use. Model upgrades are the tempting lever because they are one click, and on design work they are the lever that moves least.

## How to apply

When design output disappoints, audit inputs in this order before touching the model: brand guidelines present as a file, a named reference site with the specific elements you want called out, components lifted from a gallery, your design skill loaded, mobile checked, and a screenshot verification loop running. Reserve model changes for capability gaps you can actually name. Cost per run is still a legitimate reason to move between generations.
