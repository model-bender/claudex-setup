# Compare two runs at the same spend, not at their first outputs

## TL;DR

When one run costs far more than another, ask where the cheaper one would be if it were given the difference to keep improving, and judge on that baseline. The creator asks this question but answers it by judgment: in these videos he does not run the matched-spend follow-up, so that step is a proposed, untested pattern.

## Why it matters

Nate Herk's Fable 5.1 build cost about 1,200 dollars against about 500 for the Fable 5 build. He judged, without running it, that the cheaper build given the roughly 700 dollar difference to keep improving would have ended up better. In his GPT-6 Astra versus Fable 5.1 tests he asks the same of Astra's cheaper first versions (another 14 or 20 dollars of iteration). This lesson's inference: a first-output comparison credits the pricier run with work the cheaper one never had the budget to do.

## How to apply

Record cost per run. Before declaring a winner, either give the cheaper run a follow-up pass up to the same budget (the untested part: the creator only reasoned about it) or, as he did, weigh the pricier result against the cost gap.
