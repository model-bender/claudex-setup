# Extended Thinking Now Runs by Default With an Automatic Token Budget, No Magic Words Needed

## TL;DR

You no longer need to type 'think', 'think hard', or 'ultrathink' to get Claude Code to reason before acting; extended thinking is on by default with its own capped thinking-token budget.

## Why it matters

Older habits of typing trigger words for deeper reasoning are unnecessary overhead now; Claude Code decides on its own when to spend part of its thinking budget before acting.

## How to apply

Just describe the task normally, even for multi-step or complex work. Claude Code allocates a reasoning budget (capped by a max thinking-token setting) automatically before acting, without needing 'ultrathink' or similar phrases.
