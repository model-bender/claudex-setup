# Type 'fast' in a Codex Chat to Toggle Fast Mode

## TL;DR

Typing the word "fast" as a message in a Codex thread flips the current session into fast mode; typing it again turns it back off.

## Why it matters

Fast mode trades more tokens and cost for speed, so knowing the exact toggle phrase matters when you actually need it on a deadline.

## How to apply

Type `fast` as a chat message in a Codex thread to enable fast mode; type it again to disable it.
