# Switch to Gemini CLI When You're Going in Circles on a Visual/Aesthetic Task

## TL;DR

If Claude Code keeps missing on a UI or visual-aesthetics problem, route that specific task to Gemini CLI instead, since Gemini models show better visual understanding and aesthetic judgment.

## Why it matters

This is a concrete routing rule from direct comparison: for visual understanding and aesthetics specifically, Gemini outperforms Claude in the speaker's experience, so switching tools beats continuing to iterate.

## How to apply

When stuck in a loop on a visually-driven task (UI polish, aesthetic judgment calls), hand that specific task to Gemini CLI instead of continuing to retry in Claude Code.
