# If Legitimate Cyber or Life-Sciences Work Trips Safeguards, Apply for Mythos Access Rather Than Re-Prompting Around It

## TL;DR

Claude Mythos 5.1 is capability-identical to Fable 5.1 but ships more permissive safeguards, and it is only reachable through two trusted-access programs: the cyber verification program and the life sciences verification program.

## Why it matters

Nate Herk reads this straight off the release material: Mythos is described as identical to Fable 5.1 except that it relaxes the cybersecurity and life sciences restrictions for vetted individuals and organisations. If your work sits in those domains, the refusals you keep hitting are policy, not prompt quality, so rewording is wasted effort and the supported route is verification. The same release also claims improved safeguards that reduce false positives on the general model, so re-test before assuming you need the program at all.

## How to apply

First confirm the refusal is actually domain policy and not a prompt problem, by re-running on the current general model. If it is policy and your work is genuinely in scope, apply to the relevant verification program (cyber or life sciences) for Mythos access. Do not build prompt workarounds for safeguard refusals, and note that Mythos is only available to accepted programs, so it is not a switch you can flip in settings.
