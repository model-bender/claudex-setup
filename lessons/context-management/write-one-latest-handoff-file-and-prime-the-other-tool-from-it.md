# End Sessions With a /handoff That Marks One File as Latest, and Start the Next Tool With /prime

## TL;DR

Mark replaced accumulating plan.md files with a /handoff skill that records where you are, what was decided and the next step, plus a note that it is the latest. /prime in the other tool reads the latest.

## Why it matters

He says plan files pile up with different dates and scopes and expire quickly. The handoff series is also a decision history that can be read without bloating context.

## How to apply

Write a handoff skill (marks latest) and a prime skill (finds latest). Mark offers his versions in the video's linked resources; the contents are not in the transcript.
