# Give Each Distinct Project Its Own Folder to Keep Claude's Context Scoped

## TL;DR

Keep entirely separate projects (a product, a client engagement, an internal tool) in their own top-level folders so opening Claude on one only exposes it to that project's files.

## Why it matters

The presenter's structure has unique folders for 'build partner, clients, my internal OS,' and points out this 'makes it super easy for me to select it from the Claude desktop app' and 'limit the context provided to Claude so that it's only looking at what's important.'

## How to apply

Create one top-level folder per genuinely distinct project rather than nesting unrelated work under a shared root, and open/select the specific project folder in Claude before starting work on it.
