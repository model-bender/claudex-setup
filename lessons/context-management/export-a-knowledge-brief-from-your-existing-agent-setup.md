# Onboard a new agent with a markdown brief exported from your existing setup

## TL;DR

When you bring up a new agent, do not re-explain yourself. Ask your existing Claude Code or Codex setup to extract everything it knows about you and your business into one markdown file, hand that file to the new agent, and tell it to ask what is still missing.

## Why it matters

The existing setup already holds the context, skills and processes built up over months. The creator's advice when onboarding a hosted agent is to carry that over as a brief rather than answer the new agent's onboarding questions one by one.

## How to apply

In your current Claude Code or Codex project, prompt along the lines of the video: 'I'm trying to have a new AI agent understand everything about me and my business. Extract all your knowledge about me and give me a markdown file so I can give it to this agent.' Give the file to the new agent with: read this brief, ask me any other questions you might have.
