# Run Claude Code or Codex on an always-on cloud computer by signing in once and cloning your repo

## TL;DR

Nate runs Claude Code and Codex inside his Grok bot agents' cloud computer: ask the bot to install the CLI, sign in yourself, then clone your repo.

## Why it matters

The machine is always on, so Claude Code is available from his phone using his own subscription. He prefers API keys over desktop-app plugins so migration is one file.

## How to apply

Tell the agent to open the terminal and install Claude Code (or Codex). It prompts a sign-in; you authorize it. Clone the AI OS repo and projects, then transfer the single file holding your API keys so skills, CLAUDE.md and AGENTS.md work as on your desktop.
