# Create Skills Task-First: Do the Task, Ask for a Skill, Run It, Then Correct and Enhance It

## TL;DR

Austin's four steps: do the task, tell the AI to create a skill from that conversation, run the skill, and if the output is wrong correct it and say 'Based on this conversation, enhance the skill.'

## Why it matters

He contrasts it with collecting every skill found online, and says skills accrue direction over time.

## How to apply

Follow the four steps in one session so the corrections become part of the skill.
