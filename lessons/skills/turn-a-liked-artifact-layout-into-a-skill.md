# When an Artifact Format Works, Ask Claude to Turn It Into a Skill That Outputs That Template

## TL;DR

Austin iterated an artifact until it looked like his Instagram graphics, then asked for a skill called IG graphic creation whose artifact output is that format.

## Why it matters

It makes a one-off handoff format repeatable. His example replaced a text list in Notion with an artifact that places the text where it will sit on the graphic, so the designer sees the layout and needs fewer round trips.

## How to apply

1. Build a proof-of-concept artifact for a handoff you do repeatedly.
2. Iterate until the style is right.
3. Say: create a skill called <name> where the artifact output is this format.
4. Use the skill next time.
