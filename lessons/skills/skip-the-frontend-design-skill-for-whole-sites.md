# Skip the Frontend Design Skill for Whole Sites, Build the Design System in Claude Design First

## TL;DR

Do not reach for the built-in frontend design skill to generate a website. Generate a real design system in Claude Design (core elements, dashboards, landing page, colours, typography, shape, pill styles) and build against that instead.

## Why it matters

The complaint is convergence: the skill's own steering makes every site it produces look like every other site it produces, which is a second flavour of AI slop rather than an escape from it. A design system generated with a little input and a little time gives you tokens and components that are yours, and the result reads as professional next to the skill's output. This contradicts the older advice to install that skill, and it is the later judgment.

## How to apply

Open Claude Design, generate and publish a design system with your own brand input, then hand Claude Code the system (or its export) as the source of truth for the build. Keep the frontend design skill uninstalled so it cannot silently steer generations back to its house style.
