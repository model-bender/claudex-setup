# Teach Claude Design a Framework by Attaching Its SKILL.md to the Project

## TL;DR

Claude Design has no skills directory, but you can download a skill's raw markdown and attach it as a project **file**, dropping in a motion-graphics skill's markdown had Design use it to write rendered animation.

## Why it matters

This is the workaround to [[bracket-claude-design-with-claude-code-skills]]: Design cannot *load* your custom skills, but it can *read* one you hand it as a file. That makes any published skill markdown usable inside a hosted product with no config surface.

Design can animate HTML unaided, but the skill "has a lot of elements and makes it a little bit better", the same launch video went from bland bullet reveals to a scroll-stopping animated opener.

## How to apply

Download the skill's raw `.md`, open a project from template → animation, select your design system, and attach the skill markdown alongside your brand-concept doc:

> You have the design system, the brand concept, and the Hyperframes markdown, which teaches you how to create the motion graphics and render the animation. Target a landscape 20-30 second launch video announcing X with a CTA.

When the first pass is flat, direct it like a video editor rather than an engineer, "make this fast-paced, tell a story, more motion graphics, bullet points are boring". The high-level emotional note does translate into code.
