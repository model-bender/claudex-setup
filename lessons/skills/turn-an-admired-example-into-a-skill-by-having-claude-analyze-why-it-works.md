# Turn an Example You Admire Into a Skill by Asking Claude Code to Analyze Why It Works

## TL;DR

Download a finished piece you like, ask Claude Code to explain why it is good, then ask it to turn that analysis into a reusable skill and apply the skill to your own brand.

## Why it matters

The creator saw a motion-graphics reel on X, downloaded it, gave it to Claude Code, and said to analyze what makes it good and turn that into a skill. They then used the resulting skill, with their own assets and brand instructions, to produce a similar reel for a different subject. They put the skill in a folder and feed back what they liked and disliked after each run so it improves.

## How to apply

1) Save the reference output locally. 2) In Claude Code, ask it to analyze the file and work out why it works, then to write that up as a skill. 3) Invoke the skill with your own assets and a branding instruction in the prompt. 4) After each run, tell Claude what to keep and change and ask it to update the skill.

Verified: Technique is a prompt pattern with no flag or setting to check. Skills exist in Claude Code 2.1.287 (skill tooling referenced throughout the corpus). The claim that the resulting reel was good is the creator's opinion.
