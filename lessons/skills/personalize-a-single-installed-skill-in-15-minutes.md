# Spend 15 Minutes Personalizing Any Marketplace Skill Right After Installing It

## TL;DR

Right after installing one marketplace skill, spend about 15 minutes adding a reference file with your brand voice and 3-5 example outputs you'd approve of, then add a one-line pointer in skill.md telling Claude to consult it before writing.

## Why it matters

The speaker compares an un-customized marketplace skill to 'hiring a consultant who's never been briefed on your business': competent but generic output with no brand stamp. His stated fix is specific and time-boxed: 'spend 15 minutes customizing it. Add a reference file with your brand context and drop in three to five examples of what you actually like the output to look like.'

## How to apply

After installing a single skill, create a reference file (e.g. references/brand-voice.md) containing your tone notes and 3-5 example outputs you like. Edit the skill's skill.md to add one line such as 'refer to my brand references before you write anything.' This is a lighter, per-skill version of maintaining a full shared brand-context folder across many skills.
