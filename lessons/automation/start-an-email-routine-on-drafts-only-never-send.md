# Start an email-handling routine on drafts only, never auto-send

## TL;DR

Tell the routine to create drafts for replies and not send mail, at least while the automation is new.

## Why it matters

Jono Catliff's disaster scenario is an email sent by mistake that makes you sound unprofessional. Their routine drafts replies to personal mail, forwards accounting mail with attachments, and has a stated rule: do not send an email, only drafts.

## How to apply

Put the rule in the routine prompt as an explicit guardrail beside the sorting and forwarding steps. Review drafts for a while before allowing any sending.
