# Cap Each File in a Shared Brand-Context Folder at 50-100 Lines

## TL;DR

When building a shared 'business brain' folder (tone of voice, audience, ICP, positioning, standards) that every skill references, keep each individual file to roughly 50-100 lines rather than one large brand document.

## Why it matters

A single 2,000-line brand bible defeats the purpose of a shared context folder because skills still load too much at once; per-file caps keep it lean the same way SKILL.md itself should be.

## How to apply

Split the shared context folder into small single-topic files (tone-of-voice.md, audience.md, positioning.md, standards.md, etc.), each capped around 50-100 lines, and have each skill's SKILL.md reference only the specific file it needs at the point it needs it.
