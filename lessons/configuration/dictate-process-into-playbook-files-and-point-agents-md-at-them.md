# Turn Tacit Know-How Into Playbook Files Referenced From AGENTS.md Instead of Skills

## TL;DR

Mark Kashef had a client dictate her launch and webinar process for an hour, saved it as two plain markdown files in a playbooks folder, and had AGENTS.md reference them for relevant tasks, rather than building skills.

## Why it matters

The client ran marketing campaigns and funnels, had watched tens of tutorials and kept two unused second brains, but had never written down what makes her good. In the after state she had one unified AGENTS.md, a playbooks folder with launch.md and webinar.md, and a clients folder with a nested AGENTS.md per client. This also cured her launch assets for client A leaking into client B. Kashef says the agent just reads the playbook whenever a task is relevant, with no skill needed.

## How to apply

1. Dictate the steps of one recurring process (how you start, ideate and produce the first version) for as long as it takes.
2. Have the agent turn the transcript into one markdown file per process, such as launch.md or webinar.md, in a playbooks/ folder.
3. In the root AGENTS.md, add one line per playbook saying when to read it. Keep client-specific rules in a nested AGENTS.md inside each client folder.
Whether a playbook beats a skill (its description is not loaded every session) is the lesson's inference, not a claim in the transcript.
Checked: no flag or setting is named. Nested AGENTS.md loading is covered by existing lessons.
