# Run Claude Code Inside Google's Free Antigravity IDE via Its Extension Marketplace

## TL;DR

Antigravity, Google's free desktop coding workspace, lets you search 'Claude' in its extensions panel and install Claude Code directly, and it also has its own free built-in agent builder as a fallback if you don't have a Claude subscription.

## Why it matters

Gives a non-technical user a ready-made project workspace for Claude Code without setting up a terminal themselves, and gives a genuinely free path to try agentic building before paying for Claude.

## How to apply

Download Antigravity, open its Extensions panel, search 'Claude', install the Claude Code extension, open/create a project folder, then launch Claude Code from the panel. Without a Claude subscription, use Antigravity's own built-in agent builder button instead.
