# Keep Your Personal CLAUDE.md to a Two-Line Pointer at the Shared Team File

## TL;DR

Boris Cherny's own personal CLAUDE.md is only about two lines long and just points to the team's shared CLAUDE.md, rather than duplicating or layering personal content on top of it.

## Why it matters

Duplicating team rules into a personal file creates two sources of truth that drift apart; a pointer keeps the team file authoritative while still letting the hierarchy load it automatically.

## How to apply

In your personal/user-level CLAUDE.md, write only a short reference to the shared project CLAUDE.md's path or purpose, and keep the actual rules content in the one shared, git-tracked file.
