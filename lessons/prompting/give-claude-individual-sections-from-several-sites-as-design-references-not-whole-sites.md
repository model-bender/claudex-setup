# Give Claude Design References as Single Sections From Several Sites, Not Five Whole Websites

## TL;DR

With no direction, Claude builds a safe generic site (centred layout, default font, emojis). Hand it three to five saved reference links, each a specific section such as a hero or a pricing block, so it can mix ideas into something new.

## Why it matters

Tristen's advice is "don't pick five whole websites that you like and give it to Claude for inspiration. Pick five sections that you liked from each one of them", the way a designer builds a mood board from pieces of many sites. This is stated advice: his before/after demo does not test it, because the "after" build was given five whole sites found by his own tool and Claude chose which sections to use.

## How to apply

1) In a reference library such as Mobin, find the section you like from each site (hero from one, pricing from another) and save each. 2) Copy each section's link. 3) Paste the links to Claude with a line such as 'I like this one, please use it for inspiration', one per section. The Mobin MCP connector (paid plans only) lets Claude read them directly, but pasted links are the basic route. Checked: n/a (a prompting practice).
