# Ask Claude for the absolute path of a file it built and paste it into the browser

## TL;DR

For an HTML slideshow, dashboard or page, ask Claude to open it in Chrome or give the absolute path, then paste that path into the address bar.

## Why it matters

Jono Catliff says the URL bar showed a file path rather than a website: the direct location of the file on the machine. Pasting that path displays the file, which they say they learned too late and which saves time on any HTML output.

## How to apply

Prompt: open the file in Chrome, or give me the absolute path. Better, put 'always give the absolute path to anything you build' in CLAUDE.md, which they do so they can open results right away.

Verified: No mechanism claims (no flag or command).
