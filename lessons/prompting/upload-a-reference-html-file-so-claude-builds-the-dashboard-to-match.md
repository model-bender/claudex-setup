# Upload a reference HTML file so Claude builds a dashboard with the same layout

## TL;DR

To get a repeatable dashboard look, hand Claude an example HTML file and build on it instead of describing the layout in words.

## Why it matters

In two videos Jono Catliff gives viewers a downloadable HTML dashboard file and tells them to upload it into Claude, so the dashboards Claude builds for their own data look identical to his. It replaces a long description of the layout with a concrete artifact.

## How to apply

1. Save or download a dashboard HTML file whose layout you want.
2. Upload it into the Claude Code chat along with the prompt that fetches and organises your data.
3. Ask Claude to build the new dashboard following that file's design.

Inference, not from the source: The step about asking Claude to follow the file's design is implied by his instruction to upload it so the dashboard looks the same. He does not quote the exact wording of that request, and the contrast with describing the layout in words is the lesson's framing, not his.
