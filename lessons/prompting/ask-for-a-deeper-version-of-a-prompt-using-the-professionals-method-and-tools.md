# Rewrite a Prompt to Go Deeper, Not Bigger: Ask What a Top Professional Would Do and Which Tools They Use

## TL;DR

Ask Claude to name what a top professional would do that you are not asking for, the rawest starting material, the methods and tools, and what would independently show the result is right, then rewrite your prompt.

## Why it matters

Ray Amjad relays Felix's 'depth' idea: asking Claude to act like a professional changes vocabulary, not method (a markdown table where a data scientist would use a database and a statistical model). His performance example: 'make it faster' gets lazy loading and memo, while insisting on a performance engineer's tools means profiling and reading traces to find the slow database queries.

## How to apply

Prompt from the article as described: 'I want a deeper version of this task, not a bigger one. Before rewriting, say what a top professional in the field would do here that I'm not asking for. Name the rawest material they would start with instead of what has already been digested for me. Name the specific methods and tools they would use. What, other than you or me, would show that this result is right? Then rewrite my prompt.' The last question doubles as the verifier. You do not need to know the tools, only insist they are used.
